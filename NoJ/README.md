# 886 Slot Machine

一個互動式角子老虎機網頁。玩家點擊機台或拉把區域後，轉輪會開始亂數跳動，拉把會有假 3D 下拉動畫，並播放合成音效。結果停下後，符合指定數字時會在機台底部顯示文字提示。

## 開啟方式

如果本機測試伺服器已經啟動，可以直接打開：

```text
http://localhost:8088/
```

如果需要重新啟動伺服器，請在專案資料夾執行：

```bash
python3 -m http.server 8088
```

然後到瀏覽器開啟 `http://localhost:8088/`。

## 檔案結構

```text
NoJ/
├── index.html
├── slot machine.png
├── driver.png
├── SMO.psd
└── README.md
```

- `index.html`：主要網頁、樣式、互動邏輯與音效合成都在這個檔案。
- `slot machine.png`：老虎機主體圖。
- `driver.png`：拉把疊圖，用於下拉動畫。
- `SMO.psd`：設計原始檔。

## 目前玩法規則

- 點擊機台即可拉把並開始轉動。
- 轉動期間三個轉輪會快速顯示隨機數字與少量符號，讓玩家無法提前猜到結果。
- 結果會停在三位數。
- 隨機結果可以自然出現 `886`。
- 若連續兩次都沒有出現 `886`，下一次會保底出現 `886`。
- 只要出現 `886`，保底計數就會重置。

## 文字提示

只有以下指定結果會顯示文字提示：

```text
777 -> loser
444 -> hahaha
886 -> Target number is 88
```

其他隨機三位數只會顯示在轉輪上，不會出現文字提示。

## 視覺設定

- CSS 顯示視窗寬度上限為 `400px`。
- 老虎機維持 `1200:1050` 的原始圖像比例。
- 實際顯示高度會依比例約為 `350px`。
- 結果提示會以黑色小視窗出現在機台底部，並停留到下一次拉把。

## 音效

音效使用瀏覽器 Web Audio API 即時合成，不需要額外音檔：

- 拉把下拉聲
- 轉輪 tick 聲
- 結果停下後的短音效

瀏覽器通常需要玩家第一次點擊後才允許播放音效。
