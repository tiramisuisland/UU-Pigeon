# Truth Popup Video

這是一組以網頁 popup 視窗播放影片的靜態頁面。主頁負責啟動與排列 popup，子頁負責播放單支影片。

## 檔案

- `index.html`：主入口頁，點擊中央按鈕後依序開啟影片 popup。
- `popup-video.html`：一般影片 popup 頁面，給 `V1`、`V2`、`S1`、`S2` 使用。
- `M1.mp4`：第一個開啟的主影片。
- `V1.mp4`、`V2.mp4`、`S1.mp4`、`S2.mp4`：後續依序彈出的影片。

## 啟動方式

建議用本機伺服器開啟，不要直接用 `file://`，popup 和影片載入會比較穩。

在此資料夾執行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

然後打開：

```text
http://127.0.0.1:8080/
```

## 目前行為

- 點擊主頁中央按鈕後，第一個 popup 永遠是 `M1.mp4`。
- `M1` 會固定出現在螢幕正中央。
- `M1` 會嘗試在同一次點擊中直接有聲播放。
- 如果瀏覽器擋掉有聲自動播放，`M1` 會退回靜音播放，避免黑畫面。
- 其他影片會依序彈出，並散布在 `M1` 周圍。
- `S1` 和 `S2` 不相鄰；`V1` 和 `V2` 不相鄰。
- 所有 popup 視窗尺寸都跟隨影片原始像素尺寸。
- popup 內容只顯示影片本身，沒有自製標題列、聲音按鈕或提示文字。
- 關閉 `M1` popup 時，其他已開啟的 popup 會一起關閉，尚未彈出的 popup 也會取消。

## 瀏覽器注意事項

瀏覽器通常會限制有聲自動播放。這個頁面已經把 `M1` 的播放動作放在使用者點擊事件中，但不同瀏覽器或網站設定仍可能阻擋聲音。

測試時請允許：

- 彈出式視窗 popup
- 聲音或自動播放音訊

如果只看到影片但沒有聲音，通常是瀏覽器的自動播放聲音政策造成。

## 修改影片順序或延遲

在 `index.html` 裡修改 `baseSequence`：

```js
const baseSequence = [
  { id: "M1", src: "M1.mp4", delay: 0, sound: 1 },
  { id: "V1", src: "V1.mp4", delay: 900, sound: 0 },
  { id: "S1", src: "S1.mp4", delay: 1550, sound: 0 },
  { id: "V2", src: "V2.mp4", delay: 2200, sound: 0 },
  { id: "S2", src: "S2.mp4", delay: 2850, sound: 0 }
];
```

- `delay` 單位是毫秒。
- `sound: 1` 代表嘗試有聲播放。
- `sound: 0` 代表靜音播放。
